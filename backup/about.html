Who I Am

Hello! I'm Meghana Acharya, a Web Developer based in Hubli, Karnataka. I graduated with a Bachelor of Engineering in Computer Science from KLE Technological University in 2024. My journey into web development began in my second year of college when I built my first website — a simple blog — and fell in love with the process.

Since then, I've dedicated myself to mastering the craft of web development, from semantic HTML and responsive CSS to complex React applications and robust Laravel backends. I believe that every great website is built on a foundation of clean, purposeful code paired with thoughtful design decisions.

Outside of coding, I enjoy reading about UX design principles, contributing to open-source projects, and mentoring junior students in web technologies.

Learning Journey

My learning has been a blend of formal education and self-directed exploration. During college, I built a strong foundation in computer science fundamentals. Outside the classroom, I completed certifications in React, Laravel, and MySQL — applying each new skill to real projects.

I believe in learning by building. Each project has taught me something new — whether it was how to optimize database queries, structure a React component hierarchy, or implement secure authentication flows in Laravel.
